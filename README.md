# NGS Telegram Group Moderator & Olympiad Mini App

Telegram-бот для автоматической модерации супергруппы с темами + **Telegram Mini App / веб-портал «NGS Олимпиадник»** для регистрации учеников на олимпиады и конкурсы с **Админ-панелью и экспортом в Excel (.xlsx)**. Рассчитан на деплой в **Vercel** и работу с базой данных **Neon (PostgreSQL)**.

## Стек технологий
- **Node.js** (ES Modules, единая точка входа `index.js` для Vercel)
- **[grammY](https://grammy.dev/)** — Telegram Bot API (вебхук `POST /`)
- **@vercel/postgres** — Neon PostgreSQL
- **ExcelJS** — генерация многолистовых отчётов `.xlsx` и импорт списков учеников/учителей из Excel

## Основные функции

1. **Модерация темы «Галерея» (`GALLERY_THREAD_ID = 18`)**
   - Разрешены только сообщения с медиафайлами; текстовые сообщения без медиа удаляются.

2. **Предмодерация темы «Олимпиады» (`OLYMPIAD_THREAD_ID = 15`) + авто-выгрузка в Mini App**
   - После одобрения поста супермодератором (`SUPER_MODERATOR_ID = 8297487103`) — либо при прямой публикации супермодератором — бот автоматически:
     1. Сохраняет олимпиаду в таблицу `olympiads` в PostgreSQL.
     2. Публикует пост в тему `#15` с кнопкой **«🎓 Зарегистрировать ученика»**, открывающей Mini App сразу на этой олимпиаде.
     3. Прикрепляет авто-опрос **«Ознакомлен(а)?»**.

3. **Telegram Mini App и веб-портал регистрации (`/`)**
   - Выбор учителя («Кто регистрирует») с автоопределением по Telegram ID.
   - Всплывающий селект классов с поиском, фильтрацией по параллелям и счётчиками регистраций.
   - Таблица учеников выбранного класса со встроенным всплывающим селектом олимпиад в каждой строке (один ученик может быть записан на несколько олимпиад и конкурсов).

4. **Админ-панель (`/admin`) и экспорт в Excel**
   - Автоматический вход для супермодератора/админа при открытии из Telegram, либо по паролю в браузере.
   - Сводка: сколько учеников на какую олимпиаду зарегистрировано и пофамильный список участников с разбивкой по классам.
   - Журнал всех регистраций («кто кого и куда зарегистрировал») с фильтрами по олимпиаде, классу и учителю.
   - **Скачивание в Excel (`.xlsx`)** — 4 листа: *Сводка по олимпиадам*, *Список регистраций*, *По классам*, *По учителям* (полный или отфильтрованный отчёт).
   - Импорт классов, учеников и учителей из `.xlsx` или вставкой из Excel + готовый шаблон `.xlsx`.

## Команды бота
- `/start` — запуск бота; в ЛС показывает кнопки открытия Mini App и Админ-панели.
- `/app` — быстрая кнопка для открытия портала регистрации олимпиад.
- `/status` — сводка по правам, БД, модераторам, числу олимпиад и регистраций.
- `/list_pullers`, `/set_puller <ID>`, `/remove_puller <ID>` — управление модераторами.
- `/init_db` — принудительная инициализация всех таблиц БД.

## Переменные окружения (Vercel)
- `BOT_TOKEN` — токен Telegram-бота от `@BotFather`.
- `POSTGRES_URL` — строка подключения к Neon PostgreSQL.
- `ADMIN_ID` *(опционально)* — Telegram ID владельца бота.
- `ADMIN_PASSWORD` *(рекомендуется)* — пароль для входа в `/admin` из браузера (по умолчанию `ngs2026`).
- `WEB_APP_URL` *(опционально)* — публичный URL вашего проекта на Vercel (например, `https://your-bot.vercel.app`), если нужно зафиксировать домен явно.
- `MINI_APP_SHORT_NAME` *(для открытия Mini App прямо поверх группы)* — короткое имя Mini App, созданного в `@BotFather` через `/newapp` (например, `olympiad`). Тогда кнопка под постом использует формат `https://t.me/<bot>/<short_name>?startapp=ol_<id>`.
