# NGS Telegram Group Moderator

Telegram-бот для автоматической модерации супергруппы с темами (форума), рассчитанный на деплой в **Vercel** и работу с базой данных **Neon (PostgreSQL)**.

## Стек технологий
- **Node.js** (ES Modules)
- **[grammY](https://grammy.dev/)** — фреймворк для Telegram Bot API (режим вебхуков)
- **@vercel/postgres** — подключение к облачной PostgreSQL (Neon)

## Основные функции

1. **Модерация темы «Галерея» (`GALLERY_THREAD_ID = 18`)**
   - Разрешены только сообщения с медиафайлами (`photo`, `video`, `document`, `animation`, `video_note`).
   - Текстовые сообщения без медиа автоматически удаляются, а бот отправляет временное предупреждение на 5 секунд.

2. **Авто-опросы в теме «Олимпиады» (`OLYMPIAD_THREAD_ID = 15`)**
   - Если сообщение в тему отправляет пользователь, чей ID добавлен в таблицу `moderators`, бот автоматически прикрепляет к сообщению неанонимный опрос **«Ознакомлен(а)?»** (`Да` / `Ознакомлюсь позже`).

## Команды бота
- `/start` — проверка работоспособности бота.
- `/init_db` — создание таблицы `moderators` в базе данных (доступно администраторам).
- `/set_puller <ID>` — добавление Telegram ID пользователя в список модераторов (доступно администраторам).

## Переменные окружения
- `BOT_TOKEN` — токен Telegram-бота от `@BotFather`.
- `POSTGRES_URL` (и сопутствующие переменные Vercel Postgres / Neon) — строка подключения к БД.
- `ADMIN_ID` *(опционально)* — Telegram ID владельца бота для выполнения команд управления из личных сообщений.
