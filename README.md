# NGS Telegram Group Moderator

Telegram-бот для автоматической модерации супергруппы с темами (форума), рассчитанный на деплой в **Vercel** и работу с базой данных **Neon (PostgreSQL)**.

## Стек технологий
- **Node.js** (ES Modules)
- **[grammY](https://grammy.dev/)** — фреймворк для Telegram Bot API (режим вебхуков)
- **@vercel/postgres** — подключение к облачной PostgreSQL (Neon)

## Основные функции

1. **Модерация темы «Галерея» (`GALLERY_THREAD_ID = 18`)**
   - Разрешены только сообщения с медиафайлами (`photo`, `video`, `document`, `animation`, `video_note`).
   - Текстовые сообщения без медиа автоматически удаляются, а бот отправляет временное предупреждение на 5 секунд.

2. **Предварительная модерация и авто-опросы в теме «Олимпиады» (`OLYMPIAD_THREAD_ID = 15`)**
   - **Супермодератор (`SUPER_MODERATOR_ID = 8297487103`)**:
     - Публикует сообщения в тему сразу без предварительной проверки, и бот автоматически прикрепляет к ним неанонимный опрос **«Ознакомлен(а)?»** (`Да` / `Ознакомлюсь позже`).
   - **Остальные модераторы из БД (`moderators`)**:
     - Любое отправленное или пересланное сообщение (включая медиа и альбомы) в теме «Олимпиады» сразу удаляется из темы.
     - Вместо него на **10 секунд** появляется персонализированное уведомление о предварительной модерации (с кнопкой подключения ЛС-уведомлений), после чего оно автоматически удаляется.
     - Публикация отправляется в ЛС супермодератору (`8297487103`) с кнопками **«✅ Опубликовать»** и **«❌ Отменить»**.
     - При нажатии **«✅ Опубликовать»** бот публикует пост (со всеми вложениями и форматированием) в тему «Олимпиады» для всех участников и сразу прикрепляет к нему авто-опрос **«Ознакомлен(а)?»**.
     - При нажатии **«❌ Отменить»** супермодератор пишет причину отклонения. Эта причина вместе с копией исходного поста отправляется **только в ЛС автору** (в тему группы ничего не дублируется).

## Команды бота
- `/start` — проверка работоспособности бота и активация получения ЛС-уведомлений от бота.
- `/status` — подробная сводка: ваш ID, права администратора, супермодератора и модератора, ID текущего чата и темы, состояние БД и список модераторов (если вызвать в ответ на сообщение другого пользователя — покажет также его ID и статус).
- `/list_pullers` — вывод информации о супермодераторе и нумерованного списка всех модераторов из базы данных (доступно администраторам и модераторам).
- `/set_puller <ID>` — добавление Telegram ID пользователя в список модераторов (также работает ответом на сообщение пользователя без указания ID; доступно администраторам и супермодератору).
- `/remove_puller <ID>` — удаление Telegram ID пользователя из списка модераторов (также работает ответом на сообщение пользователя; доступно администраторам и супермодератору).
- `/init_db` — создание/обновление таблиц `moderators` и `moderation_queue` в базе данных (также выполняется автоматически при первом запросе).

## Переменные окружения
- `BOT_TOKEN` — токен Telegram-бота от `@BotFather`.
- `POSTGRES_URL` (и сопутствующие переменные Vercel Postgres / Neon) — строка подключения к БД.
- `ADMIN_ID` *(опционально)* — Telegram ID владельца бота для выполнения команд управления из личных сообщений.
